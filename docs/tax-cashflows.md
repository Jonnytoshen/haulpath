# 税费与项目现金流

19 的参数化年度核对消费同方案显式选定的完整运营及资产账目，不按目标运量另算收入。规则由用户配置并注明来源，不内置地区税制。业务边界沿用一体化或仅站方；项目现金流不含借款、还本、利息和股本。融资及其利息税务影响由20/21接入，折现和增量评价由22接入。

## 采用依据与年份

保存 `taxCashflows` 推进输入版本；核对时显式传入运营及资产结果身份。运营价格、年度物理输入、源年度任务完整物理快照、资产输入及完整站网必须与当前输入等价。只有明确的运营、资产、税务字段及非正式结果容器从物理比较排除，站网原价、预算和车队仍比较。原账目不改写，不跨年度任务拼接年份。

沿用资产评价年份（可含首年建设期），本版完整结转要求连续财年；存在空档时列缺口并停止后续完整结转，不把相隔数年的两行当作相邻年度。每个非运营年须显式声明本年无运营收支并填来源；已有年度物理输入的年份必须采用对应实际运营证据，零运营天数也不能跳过年度固定费用。缺失证据不补零。

现金流均为折现前年度末收付，记录相对建设首年的实际日历年差 `period`，不默认第一行时点为0。折现时点选择留给22；本票不发布NPV、股权或融资可行结论。

## 含税、抵扣及计税

每条纳入边界的运营明细、实际电费明细和资本事件分别配置税务规则。抵销和外部排除项目不会重新进入税账；边界外资产不自动补齐税务规则，既有边界外折旧或历史税基草稿可保留，但其空值不阻断当前边界核对。规则关联稳定身份、年份及事件；电费按电源、站址、价格窗口关联。同额不等于同一税务目标。

- 含税：源账目已舍入的分位金额为实收付；未税额 = 金额 ÷ (1+税率)，逐项舍入至分，税额为两者之差。
- 不含税：源金额为未税额；税额 = 金额 × 税率，逐项舍入至分，再加为实收付。
- 明确不适用：无价外税，税率须留空、抵扣须选不适用；不等于未知或适用零税率。
- 税率使用0至1的小数（如0.1），最多6位小数，零须显式填入。支出的进项抵扣须明确允许或不允许并注明适用来源；收入选择不适用抵扣。仅当税额适用且允许抵扣才计进项。不可抵扣进项并入费用或资产税基。
- 所得税处理逐项选择纳入或排除：运营收入纳入计税、费用纳入扣除；投资纳入形成折旧税基，不立即扣除；回收纳入时按未税收入减可扣除剩余税基计处置损益。排除回收时也不扣其剩余税基。

采用年度统一销项减进项，期初留抵必须显式输入（含零及来源），未抵完向后结转；本版无进项现金退税、无跨纳税主体划转和月度时滞。无进项项目也须显式填写期初零。本年度销项不足不产生负税款。历史资产不自动追回历史进项。

其他税费逐年显式金额（含零）、来源和所得税扣除条件。附加等复杂规则以有来源的年度金额表达，本版不按地区法定公式自动计算。

## 分类直线折旧与历史资产

分类规则显式给定年限、税务残值率、当年或次年开始及来源；年限0表示明确不折旧，仍须说明。新资产税基来自本次采用投资实付减可抵扣进项，若所得税排除则税基为0。分类规则应用于新建及每次更换的独立代际。残值率仅决定折旧底限，和18的实际残值回收金额分别表达。

历史资产逐资产显式录入期初剩余税基、剩余折旧年数、税务残值和来源；历史原值或投运年份不能代替这项确认。剩余年数0表示不再折旧。本版不从历史年份推算累计折旧，不把历史原值再列为投资现金支出。

每个代际年折旧 = (税基−税务残值) ÷ 年数，逐年舍入至分且以剩余可折旧额封顶；最后折旧年调整尾差。更换在年初发生，旧代际本年不再折旧，处置按其期初剩余税基；新代际按分类起算规则。末年残值在年末处置，先计本年折旧再核对剩余税基。不会对已处置代际继续折旧。折旧及处置剩余税基只影响所得税，不再扣现金，也不另加一笔税盾。

## 亏损及年度替代

显式配置结转年数：0表示不结转，正整数N表示损失年度后的N个日历年内可抵扣。期初损失逐笔注明发生年、剩余可用金额和来源，不假定历史原始亏损等于尚可用余额。采用最早到期优先，先剔除到期批次，再抵扣正的计税收益；负收益按本年形成新批次，不能产生现金退税。逐年列期初、到期、使用、新增及期末余额和批次。无前期损失也须在范围依据声明；未知年度使后续余额未知。

特殊税费只替代指定年份的增值税应缴、所得税应缴或其他税费，保留基准、采用额、原因和来源，不能基准再叠加。其他税费替代先进入费用及税前扣除，所得税替代仅改变现金税款；增值税替代仅改变本年现金缴款，不重算进项留抵（特殊余额须修正规则/期初依据），所得税替代不修改损失抵扣批次。未知替代金额保持缺口；不允许负税款自动退税。

## 数值与现金流政策

政策 `cny-tax-annual-half-up-6-2-v1`：先消费17/18实际已舍入金额分，按每条规则十进制BigInt有理数乘除并四舍五入至分；分类残值、年折旧、年度所得税同样舍入至分。所有相减/归集用整数分，安全整数溢出为缺口，不做浮点累计。金额输入最多12整数/6小数；源金额较早舍入的精度不会被恢复。税基、留抵和亏损按分结转。

项目现金流 = 含税口径运营实收−实付 + 资本回收−投资 + 营运资金释放−增加 − 采用增值税缴款 − 其他税费 − 所得税。资本投资不在所得税前立即扣除；营运资金只用18的增减，历史取得不再列支，预算不再列支。税务完整和融资、NPV及投资推荐分别表达。

正式输入由专用整批PUT保护修订/冻结；通用上下文不可绕过。schema9独立账目记录完整采用证据、税务输入、版本、规则和逐年账目，旧结果保留，复制不继承结论。

公开前缀 `/api/projects/:projectId/scenarios/:scenarioId/tax-cashflows`：PUT `{ expectedRevision, input }`，GET读取缺口和历史，POST `{ expectedRevision, operatingResultId, assetResultId }` 核对并返回201（资料缺失保留不完整账目；不相容证据409），GET `/:resultId` 只读本方案账目。

## 独立算例

以下均为合成约定，不是法定税率。连续三年，运营含税收入1100/2200/2200元、费用880/550/550元，价外税率0.1且费用进项可抵。新电池含税投资1100元、更换440元、更换旧件回收110元、末年回收220元；税基按未税取得额，电池2年直线、零税务残值、当年起算。历史车辆期初剩余税基300元、剩余3年、零残值，历史购置原值不列支。营运资金期初0、三年期末100/120/0元。所得税率0.25、亏损可结转5年，无期初亏损或留抵、其他税费为0。

| 年度 | 折旧 | 抵亏前计税收益 | 使用亏损 | 期末亏损 | 期末留抵 | 增值税缴款 | 所得税 | 项目现金流 |
| ---- | ---: | -------------: | -------: | -------: | -------: | ---------: | -----: | ---------: |
| 首年 |  600 |           −400 |        0 |      400 |       80 |          0 |      0 |       −980 |
| 次年 |  300 |            800 |      400 |        0 |        0 |         40 |    100 |       1160 |
| 末年 |  300 |           1400 |        0 |        0 |        0 |        170 |    350 |       1470 |

次年旧电池期初剩余税基500元，处置收益100−500=−400元；新代际折旧200元加历史车辆100元。次年经营现金1650、资本现金−330、资金增加20，再减40与100得1160元。末年经营现金1650、残值220、资金释放120，减170与350得1470元，没有再扣300元折旧或再加税盾。次年所得税有原因替代90元后，现金流1170元，仍保留基准100元和原亏损抵扣。

## 输入形状

税务输入包括 `scopeSource`、`openingVatCredit`/`openingVatSource`、`lossCarryYears`/`lossSource`、`openingLosses`、`years`、`rules`、`depreciation`、`historicalAssets` 和 `overrides`。年份/年限为整数，金额/比率为十进制文本，未知为null，来源空串可作为未完成草稿。

- 年度：`{ year, activity, source, incomeTaxRate, otherTax, otherTaxDeductible, taxSource }`，activity为operating/non-operating/null。
- 明细：`{ targetKey, pricing, vatRate, credit, incomeTax, source }`。pricing为inclusive/exclusive/not-applicable/null；credit为allowed/denied/not-applicable/null；incomeTax为included/excluded/null。targetKey由所选账目稳定身份与年份组成，页面「补齐所选账目规则」只补未知行，不填税率或推断抵扣。
- 折旧：`{ category, years, residualRate, start, source }`，分类沿用资产目录，start为service-year/next-year/null。
- 历史税基：`{ assetId, openingBasis, remainingYears, residualBasis, source }`。
- 期初亏损：`{ originYear, amount, source }`，amount为本期初尚未使用余额。
- 税费替代：`{ year, kind, amount, reason, source }`，kind为vat/income/other，原因和来源必填。

除逐项税务规则外，各列表上限1000项，文本上限2000字；逐项规则不按1000条截断，整份税务输入按UTF-8序列化上限8 MiB作资源保护；身份、年度、分类和替代目标不可重复。失效目标可保留修复但不形成完整结论。页面年度TSV每行7列：年份、activity、所得税率、其他税费、扣除条件true/false、活动来源、税费来源；空列保留，预览采用仅替代涉及年份，不覆盖同期其他编辑。

项目/融资边界的通用参考为 [ADB 财务分析指引](https://www.adb.org/sites/default/files/institutional-document/535126/financial-analysis-evaluation-guidance-note.pdf)。本功能采用的具体价税、折旧、结转及年度时点契约以上文为准，不据该参考填入地区规则或参数。
