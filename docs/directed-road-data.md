# 方案有向道路资料

打开项目中的规划方案，在“有向道路资料”区域选择“准备缺失道路”。启动立即返回任务标识，页面显示准备进度、复用数量、状态和失败原因。关闭页面后任务仍由本机服务运行；重新打开同一方案可以查询，服务停止时任务会中断。道路资料仍使用高德普通驾车服务：**未校验重卡限高、限重及货车限行**。

## 准备范围与偏好

- 业务区间按运输循环的相邻点位顺序分别准备，沿用该循环采用的线路驾车偏好。
- 各候选站址对每个业务区间分别准备“区间起点 → 站址”和“站址 → 区间终点”，沿用该循环偏好；准备道路不改变业务顺序，也不表示已满足后续绕行限额。
- 各运输循环的起点之间双向准备跨线接续道路，用于后续接续及归位依据；使用方案内“跨线接续驾车偏好”，默认“高德推荐”（`32`）。保存该偏好更新方案输入版本，不修改项目的线路偏好记忆。

同一精确坐标、方向、偏好的道路可以被多个业务位置使用。矩阵仍保留各位置、循环和站址身份，不按名称合并业务对象。完全同坐标时明确记录“同址无需行驶”、零米和空折线；其他道路采用高德返回的第一条方案，保存整数米及原有道路折线。反向道路另测，不使用反转折线或示意直线。

新候选、修正坐标或偏好后重新准备，匹配资料直接复用，仅请求缺失项。缓存按原始精确坐标匹配；即使高德请求中的六位小数文本相同，原始坐标改变后也不会沿用旧缓存。有效的循环来源道路可作为依据复用，不自动刷新源线路或循环快照。完整矩阵就绪只表示所需道路齐全，不表示循环已确认、车辆排程、能源、场地、接电、供电共享或财务已经通过校核。

## 任务与版本

任务保存项目、方案、输入版本及不可变上下文快照，并逐条持久保存成功资料。全服务一次运行一个道路准备任务，其余排队；高德请求沿用有界并发。单次上游请求超时为 15 秒，道路任务含排队的总时限为 30 分钟。配置缺失、限流、上游错误或无效返回均保留可读原因，不把部分矩阵标成完整就绪。停止或失败不删除已经准备的道路，再次启动可以复用。

输入改变或冻结使活动旧任务结束，迟到响应不会写入新版本或其他方案。旧任务及其已保存道路仍可按标识查看。冻结方案不能保存偏好或启动新准备；继续调整须先复制。副本使用新方案身份，不继承任务历史，可按精确依据复用本项目已有道路。删除项目会清理任务及缓存。

服务首次打开 SQLite 时，遗留的 `queued`、`running` 任务标记为 `interrupted`，保留快照和已保存道路；正常读取、页面刷新及开发热更新不会中断活动任务。恢复活动任务期间的在线备份也执行相同规则，用户手动发起新任务补齐缺失资料。

## 公开接口

前缀为 `/api/projects/:projectId/scenarios/:scenarioId`。项目、方案和任务均核对归属。

| 方法与路径                 | 请求及返回                                                                 |
| -------------------------- | -------------------------------------------------------------------------- |
| `GET /roads`               | 当前输入的需求矩阵、可复用道路、完整就绪状态、最近任务及历史摘要           |
| `POST /roads`              | `{ expectedRevision }`；持久化后返回 `202` 及任务标识，不等待高德完成      |
| `GET /roads/:taskId`       | 读取该任务的不可变输入快照、进度、状态及已取得道路                         |
| `POST /roads/:taskId/stop` | 停止活动任务，保留已取得资料                                               |
| `PUT /road-settings`       | `{ expectedRevision, continuationStrategy }`；保存版本化偏好并返回完整方案 |

状态为 `queued`、`running`、`completed`、`stopped`、`failed`、`timed-out`、`interrupted` 或 `superseded`。当前矩阵的 `completed/total` 与任务原快照的进度分别呈现；完整就绪要求当前矩阵全部齐全，且当前输入版本已经显式完成过准备；只有缓存齐全时仍可启动一次零请求准备。没有可准备的循环时不能启动，空矩阵不表示完整就绪。客户端不能提交道路结果、任务状态或快照。通用上下文保存必须原样保留 `roadSettings`，新偏好须走专用接口；旧方案未保存时按 `32` 解释。

SQLite schema 5 新增道路任务与项目道路缓存，方案上下文版本仍为 1。迁移保留旧资源、版本及偏好；备份、恢复和回退继续遵循[运行维护](operations.md)。边界取舍见 [ADR 0008](adr/0008-directed-roads-and-task-snapshots.md)。
