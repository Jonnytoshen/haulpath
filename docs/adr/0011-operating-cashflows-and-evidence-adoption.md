# 运营收支独立保存，显式采用同方案等价物理证据

年度能力已将代表日实际运输和购电发布为独立物理证据。年度价格保存也推进规划方案输入版本，如果要求每次调价都重跑运输搜索，会使纯价格维护承担不必要的搜索成本；若按年份或总量直接借旧证据，则可能把已改变的车队、站网、业务分配或硬约束误当作当前依据。

选择专用 `operatingCashflows` 输入和独立不可变运营账目，保留原年度任务的版本和实际道路。用户核对时显式指定同项目同方案已结束的源年度任务；服务端比较完整上下文，仅排除明确的纯运营收支字段及非正式结果容器，其余任何差异均拒绝采用。年度代表日等价比较同样排除运营价格。这一保守边界可能要求不影响排程的其他资料变更后也重跑年度能力，代价可接受；它避免维护一份容易漏掉新增物理字段的白名单。沿用 [ADR 0007](0007-frozen-scenario-version-lineage.md) 和 [ADR 0009](0009-daily-transport-worker-and-results.md) 的归属及发布保护，不跨方案继承正式证据。

正式账目记录源任务、源物理版本、本版价格快照、业务边界和数值政策，保留逐年计量及价格交集；一次核对只采用一个任务。业务边界不改变源物理结论，也不升级税费、投资、融资或净现值状态。冻结拒绝新结果写入，复制只保留输入，价格变化保留旧账目并显示历史版本。

计算只对已校验实际账目做有界归集和十进制定点乘算，不重复重放物理搜索或新增 Worker 队列；在 SQLite 事务内检查修订、冻结和源归属后一次保存至 schema7 的独立表。相比将结论放入通用 `results`，这增加一张表及迁移，但使正式发布权限与可编辑扩展资料分开，备份与恢复仍为同一数据库。收费归属、固定费用、分时电价及舍入政策见[运营收支](../operating-cashflows.md)。

## 资产资本收付扩展（18）

同一保守等价策略明确排除专用纯财务字段 `assetCashflows`，年度代表日快照也采用相同排除。资产账本不会编辑站网价格或预算硬约束；这些物理输入继续参加完整比较。独立资产归集不要求物理或运营结果，在 schema8 独立表按本版资产与完整站网快照发布；资产业务边界与运营边界不一致时保持联合评价缺口。对账只采用分类资产的资本事件一次，不叠加站型预算。年份、余额、替代目标及数值政策见[资产与资本收付](../asset-cashflows.md)。
