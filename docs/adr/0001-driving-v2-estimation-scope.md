# 使用驾车路径规划 2.0 进行行前测算

重途首版用于行前路线与距离测算，采用高德 Web 服务 v5 的[驾车路径规划 2.0](https://developer.amap.com/api/webservice/guide/api/newroute)。普通驾车测算未校验重卡限高、限重及货车限行，结果须明确说明这一能力边界。高德另有需商务开通的收费[货车专用基础路径规划](https://developer.amap.com/api/logistic-service/guide/wagon_path/truck-route-plan-basis)，本次选择维持已确认的普通驾车测算范围，不接入该能力。
