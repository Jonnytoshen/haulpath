# 按相邻点位测算并保留完整结果快照

高德[驾车路径规划 2.0](https://developer.amap.com/api/webservice/guide/api/newroute)公开返回距离及平铺的导航步骤，但没有可依赖的精确途经点区间分界契约。为使区间明细准确对应指定点位，包含 N 个点位的线路发起 N−1 次相邻点位请求，每个区间采用返回的第一条方案并按点位顺序拼合。地图、区间明细、线路总里程及表格导出使用同一份完整路线方案，线路总里程按各区间的整数米数求和后再换算展示。

## 结果保留

- 全部区间成功后，才原子替换最近一次成功的完整路线方案；任一区间失败均保留原成功结果。
- 路线方案由用户手动重算；测算输入修改后，保留旧结果并标记待重算，过期结果不作为当前线路结果导出。
- 请求只可更新其对应的测算输入，旧请求返回的结果不得覆盖新输入或其结果。
