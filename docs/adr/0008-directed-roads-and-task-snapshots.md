# 道路资料按项目复用，准备任务保留独立版本快照

方案需要复用距离和折线，同时冻结版本不能因后台请求完成而改变。道路准备因此使用独立任务与项目内道路缓存：任务绑定项目、方案身份及输入版本，保留完整输入快照和已取得资料，不向方案上下文或通用结果容器回写；复制方案保留道路偏好输入，但不复制任务身份。与把新道路写回循环快照相比，这保留了冻结输入及来源依据，代价是道路就绪必须从独立矩阵判断，不能仅检查循环引入时的道路。

缓存只匹配原始精确起止坐标、方向和驾车偏好；请求沿用高德六位小数序列化，但不能因两组原始坐标舍入相同而共用缓存。业务位置、候选站址和循环关联保留在需求矩阵中，不以名称或局部身份跨方案推断道路等价。完全同坐标的接续或进出站明确表示无需行驶，不生成道路折线；其余方向分别取得真实道路。已完成版本保留本版本任务采用的道路；新输入版本优先使用当前上下文已显式引入的有效来源道路，再采用项目缓存。冻结版本只展示最近本版本任务已采用的资料（含部分成功）、上下文固有道路及确定的同址零行驶，未显式采用的共享缓存不能使冻结后的缺口自动变化。缓存存在不等于任一版本矩阵完整，更不表示运输或工程可行。

启动接口持久化任务后立即返回，由应用服务继续准备；服务内单个道路任务运行，其余排队，沿用有界高德并发。停止、超时、输入变更或冻结后不接纳迟到资料，已保存资料与旧任务仍可核对；首次打开数据库把遗留活动任务标为中断，用户手动重试只补缺失道路。代价是进程中断后需要重新发起任务，而不恢复原请求执行位置。该决策延续 [ADR 0007](0007-frozen-scenario-version-lineage.md) 的归属与冻结规则，不交付后续运输搜索或物理、财务结论。
