# 年度运营收支

规划方案内打开「运营收支」，保存业务边界、逐年价格和来源，再显式选择已结束的年度任务核对。结果消费该任务独立校验过的实际运输、空驶、换电及购电账目；未找到周期的年份实际数量未知，不能借用目标、其他年份或其他任务补零。**运营收支完整也未校核税费、投资及融资**，不表示项目或股权现金流、净现值或投资可行。普通驾车测算仍未校验重卡限高、限重及货车限行。

## 输入与费用归属

业务边界显式选择「一体化」或「仅站方」，与后续项目/股权现金流边界分别表达。每年保存收入和运营费用的完整范围依据；没有其他项目也须明确声明，不默认配置市场价格。年份沿用年度物理输入；移除年份或站址后保留失效资料供显式修复。

各明细记录稳定身份、名称、归属、单位、十进制单价、来源及可选站址。未知单价以 `null` 保存，明确零价须填 `"0"`，零价也须有来源。

| 归属代码                   | 业务含义                     | 一体化   | 仅站方   | 可用计量单位                                 |
| -------------------------- | ---------------------------- | -------- | -------- | -------------------------------------------- |
| `transport-revenue`        | 外部支付运输方               | 收入     | 边界外   | 吨、吨公里、行驶公里、年度固定金额           |
| `external-station-revenue` | 外部支付站方                 | 收入     | 收入     | 换电次数、购电kWh、年度固定金额              |
| `internal-swap`            | 运输方支付站方的内部换电结算 | 内部抵销 | 站方收入 | 换电次数                                     |
| `transport-cost`           | 运输方支付外部               | 费用     | 边界外   | 行驶公里、空驶公里、吨、吨公里、年度固定金额 |
| `station-cost`             | 站方支付外部                 | 费用     | 费用     | 换电次数、购电kWh、年度固定金额              |

吨公里为实际补能时间轴各行驶事件的载荷乘道路公里，包括实际进出站行驶；行驶、空驶与换电也使用这份时间轴。数量只采用一份代表日，不将周期构造的多日重复事件当作额外业务。站点计量可限定一个入选站；未限定则使用全部入选站的实际业务总量。固定金额数量为1，不随运营天数变化，零运营天数仍保留该年固定费用。

站点运维口径每年二选一：逐站采用所选站型的年度运维，或用本年明细完整替代。采用站型时拒绝同时录入站方费用明细，避免重复；年度明细模式不再自动加上旧站型费用。范围依据应说明是否已含维修、人工、租赁等费用。此阶段录入约定运营收付单价；含税方式、计税和抵扣规则在税费工单独立处理，不自动推断。

## 分时购电

逐年按方案内电源身份维护购电承担方（站方、运输方或外部）及电价窗口。日内分钟范围为0至1440，开始不等于结束；结束早于开始表示跨午夜，全天使用0至1440。窗口不得重叠，须覆盖实际发生的购电区间；缺价、缺来源、缺承担方或未覆盖部分均列缺口。无实际购电区间的电源没有虚构购电费用。

电费将周期 `[0,1440)` 实际电源区间与窗口相交，按逐站电网功率积分，再乘本年运营天数。跨午夜的充电已投影到代表日，零点前已开始的实际购电也计入。完整充电预订峰值、待充需求、车辆耗电、回收电池能量均不能替代购电计费量。外部承担不纳入本边界；运输方承担在一体化计入、在仅站方排除。

计费采用逐站逐窗口年度金额，电源合计是其分摊金额之和，只有这笔费用进入年度支出，不把电源合计再加一次。页面可展开实际交集区间、功率、价格及来源。缺少覆盖时已知交集仍可查看，年度总收入、支出和余额不发布为完整值。

## 数值政策与独立案例

政策 `cny-annual-line-half-up-6-2-v1`：单价为非负十进制文本，最多12位整数、6位小数。年度数量按每条明细或每站每电价窗口聚合，四舍五入到6位小数；其百万分之一须为安全整数。与单价用 BigInt 十进制定点相乘，年度明细金额四舍五入到分，然后以整数分求年度合计；金额和汇总都限制为安全整数分位范围。超范围列缺口，未知不补零。此政策不提前决定税费、资产、融资或折现的政策。

独立案例：一辆十吨车实际每日行驶186km（包括140km载货绕站和46km空驶），换电一次，恢复341kWh电池能量需要电网购电378又8/9kWh。购电从562分钟持续到751又4/9分钟：至600分钟76kWh、600至660分钟120kWh、其后182又8/9kWh，单价分别1、2、3元/kWh。一运营日电费为864.67元。

运费100元/吨、车辆费1元/km、站点固定费30元/年、内部换电20元/次时，一体化收入1000.00、支出1080.67、余额−80.67元；仅站方收入20.00、支出894.67、余额−874.67元。目标增长至20吨但仍实际完成10吨时，不增加计费吨数。下一年单价200元/吨、运营2天时，收入4000.00元，电费1729.33元，固定费仍30.00元。两项固定费0.005元和0.015元逐项舍入为1分和2分，合计3分。

## 版本、证据与历史

`operatingCashflows` 是专用接口保护的正式输入，通用上下文不能改写。原子保存检查修订号，真实变化增加输入版本；完全相同输入不创建伪版本。输入变化后原账目按历史版本保留，页面标为历史。冻结版本拒绝输入和新结果写入；复制保留输入及来源，不继承正式结果或年度任务。

价格改变后，核对动作显式采用同项目同方案已结束年度任务的快照。服务端保守地比较完整上下文，仅排除明确的运营收支字段与非正式结果容器；年份、天数、需求身份/吨数、循环、道路依据、车队、站网和硬约束等变化均拒绝复用。采用的是源任务实际保存的有向道路，不从新缓存拼装，不改写源版本。相同年份、总量或站址名称不足以采用证据。年度代表日等价比较同样明确排除纯运营价格，物理约束和预算继续生效。

每份账目记录项目、方案、输入版本、源年度任务及物理版本、逐年证据身份、价格与年度输入快照、边界和数值政策。只用一个源任务，不拼接多任务结果。来源年度任务部分完成时，保留可核对年份并明确整体不完整；年度证据完整性、年度需求达标、运营收支完整性与全局经济状态分开表达。`economicStatus` 继续为 `not-ready`。

本次为有界的账目归集与定点金额计算，不重新运行物理搜索，也不新增后台队列。正式结果独立持久化至 schema7 的 `operating_cashflow_results`；在事务内核对修订号、冻结及证据归属并一次写入，失败不留下部分结果。旧 schema1–6 顺序迁移并保留全部既有数据和任务。备份恢复沿用[运行维护](operations.md)。

架构取舍见 [ADR 0011](adr/0011-operating-cashflows-and-evidence-adoption.md)。

## 公开接口

前缀 `/api/projects/:projectId/scenarios/:scenarioId/operating-cashflows`，所有入口检查项目和方案归属。

| 方法             | 行为                                                                                                                                    |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `PUT /`          | `{ expectedRevision, input: { boundary, years } }` 整批保存；缺价/缺来源可保存草稿，结构、精度、重复身份和窗口重叠非法则整批拒绝        |
| `GET /`          | 当前输入版本、基本资料缺口及按创建倒序的正式/历史收支账目                                                                               |
| `POST /`         | `{ expectedRevision, sourceTaskId }` 显式采用年度任务，直接返回201与核对账目；不完整输入产生清楚标记的不完整结果，物理快照不等价返回409 |
| `GET /:resultId` | 读取本方案的独立历史账目，冻结后仍可读取                                                                                                |

每年输入为 `{ year, scopeSource, stationCostMode, lines, electricity }`。明细为 `{ id, name, flow, basis, rate, source, stationId }`；单位代码为 `tonne`、`tonne-km`、`vehicle-km`、`empty-km`、`swap`、`grid-kwh`、`year`。电源电价为 `{ powerSourceId, payer, windows: [{ startMinute, endMinute, rate, source }] }`。金额输出使用安全整数分，显示两位元；空值保持未知。

表单支持逐年编辑和补齐评价年份，收支及电价分别支持TSV粘贴预览后采用；预览替换涉及年份的该类明细，其他年份/另一类资料保留，最后统一保存。没有新增文件导入或财务导出。
