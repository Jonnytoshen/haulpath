# 项目线路分布

Mode: Operate。在项目内连续浏览线路的空间分布，选择只预览，明确打开才进入编排。

THESIS: 地图负责看分布，资料栏负责认线路；名称、稳定色标和选中勾选共同建立对应。

OWN-WORLD: 继承 DESIGN.md 的纸白工作面、浅灰绿资料区、深绿交互、中文系统字体、小圆角及 Lucide 图标。不建立新的视觉系统。

FIRST VIEWPORT: 桌面地图在左并占主要宽度，右侧为独立滚动线路列表与所选摘要；列表最小高 136px，行最小高 68px，里程右对齐，选中勾选可辨。搜索筛选保持共享。摘要先列完整名称、状态与总里程，再设有序点位、偏好与有效时间的详情滚动区，打开线路位于详情区外；摘要外层保留滚动回退，使极长名称仍可完整访问。宽度至少 901px 且高度不超过 760px 时，面板高 600px，工作区纵向滚动；900px 及以下按地图、列表、摘要排列，摘要与详情自然展开。

SIGNATURE: 点击折线或列表，原色线路高亮且编号点位出现，列表以勾选和浅绿同步反馈；查看全部恢复当前匹配范围。保留视野和列表滚动恢复，无新增测算、写入或过滤规则。换至另一线路时，摘要与详情回到顶部；同一线路的普通刷新不主动重置滚动。

ACCESSIBILITY: 每行通过描述关联提供状态、点位数和有效公里数，常驻礼貌状态区域播报当前预览。所选行后提供原生“跳到所选线路摘要”链接，仅键盘聚焦时显现；激活后聚焦摘要并滚入视野，普通选线不自动转移焦点。列表、详情区与摘要保留可见焦点。

CONSTRAINTS: 七类摘要完整，无效方案的距离与时间为空缺；不绘制过期或虚构道路。固定八色按稳定标识分配。缺配置和 SDK 失败不阻断列表与打开。沿用普通驾车测算边界。

DIRECTION: 用户确认优先让地图与线路选择更清晰，保持现有功能范围。现有模块内部重构，代码优先，不做视觉世界替换，无批准视觉稿。

FINISH: 成组核对1440×900、1024×900、390×844及短桌面；浏览器真实HTTP和临时SQLite，仅高德边界替换；独立视觉与代码复核。
